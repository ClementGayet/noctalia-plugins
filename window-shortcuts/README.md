# Window Shortcuts

| Shortcut | Action |
| --- | --- |
| Alt + Tab | Open Noctalia's window switcher and cycle forward |
| Alt + Shift + Tab | Cycle backward |
| Alt + F4 | Close the focused window |

Release Alt to switch to the selected window, or press Escape to cancel. Load `hyprland/bind.lua` with `dofile` from your Hyprland configuration. Noctalia's Panels launcher lists **Window Shortcuts**, which also opens the switcher without a held modifier.
