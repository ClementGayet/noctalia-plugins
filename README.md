# Noctalia plugins

Local plugins for Noctalia 5.5 and Hyprland 0.57.

| Plugin | Controls |
| --- | --- |
| [Display Settings](display-settings/) | Display modes, scale, layout, power, and workspace assignments |
| [Smart Resize](smart-resize/) | Drag from broad edge and corner zones inside a window |
| [Tiling Preview](tiling-preview/) | Show tiled drop positions and stack windows in vertical rows |
| [Window Shortcuts](window-shortcuts/) | Switch or close windows from the keyboard |

## Add the repository to Noctalia

Add a local path source in Noctalia Settings under **Plugins → Plugin Sources**. Point it at this repository, then enable the plugins you want. Each plugin also documents its Hyprland setup.
